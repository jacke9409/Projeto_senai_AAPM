# Slides — como apresentar

Este diretório contém um arquivo Markdown com slides compatíveis com Reveal.js:

- `project_slides.md` — slides em Markdown (separados por `---`).

Como visualizar rapidamente:

1. Instale `reveal-md` (ou use outra ferramenta que suporte slides em Markdown):

```bash
npm install -g reveal-md
```

2. Abra os slides localmente:

```bash
reveal-md slides/project_slides.md --watch
```

Alternativas:
- Converter para PDF via `reveal-md` ou `decktape`.
- Pedir para eu gerar um `.pptx` (PowerPoint) automaticamente.
