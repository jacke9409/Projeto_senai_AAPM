Refatoração dos templates de índice e visualização para aprimorar a interface do usuário e a experiência do usuário (UI/UX)

- Substituímos a antiga estrutura do index.html por um novo layout com barra lateral e área de conteúdo principal para melhor navegação e acessibilidade.

- Atualizamos o visualizacao.html para incluir um cabeçalho moderno e uma seção de cartões promocionais, melhorando a estética e a funcionalidade geral.

- Adicionamos elementos de design responsivo e animações usando GSAP para uma experiência do usuário mais dinâmica.

- Implementamos um novo esquema de cores e tipografia para melhorar a legibilidade e o apelo visual.
